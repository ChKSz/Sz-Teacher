# Sz-Teacher 📐

初中数学一对一 AI 讲师：拍照或输入题目 → 分步解答 → 一键生成**带朗读的几何动画讲解**（动点会动、辅助线一步步画出来、可以拖动滑块自己观察）。

## 功能

- **解题**：打字、粘贴或拍照上传题目，解答边生成边显示，公式排版清晰；可以随时追问。
  - 输入框左下角可拍照或选择图片；点击待发送图片可以放大、旋转、裁剪，一次最多 4 张。
  - 点击输入框内的模型名称，在统一菜单中选择模型、思考强度和“先给提示 / 完整讲解”，选择会保存到服务器。
  - 点击公式按钮可插入分数、根号等 LaTeX 公式并实时预览，支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`。
  - 回答后可点“换种讲法”“给我提示”，或填写自己的解法请老师检查；桌面题目侧栏可收起，刷新后保持。
  - 消息下方提供“重试请求”和“复制内容”：重试沿用原问题、图片及当时的上下文，新结果追加保存；复制保留 Markdown 和 LaTeX 源文。
- **动画讲解**：模型把解答改写成"讲解剧本"，程序负责画图、播放、朗读。
  - 动点沿边运动、旋转、对称、函数图象、动点轨迹等常见初中图形
  - 每一步：动画 + 高亮 + 朗读；可暂停、回退、重播、拖动参数滑块
  - **验算**：程序把每个结论代回图形计算，不成立就让模型修正；仍不通过会标出"验算未通过"
  - 某一步没看懂，点"🙋 这步没懂"直接追问
  - 暂停后可“重播本步并继续”，不会跳过未讲完的内容；支持全屏看图和文字步骤目录。
  - 生成中可以切换题目或刷新，题目列表显示进度状态；失败后可重试，重新生成失败时保留原来的动画。
- **错题本**：收藏题目、写错因笔记，侧边栏筛选和搜索
  - 支持知识点、错因、待复习 / 已掌握状态，保存后在其他设备上也可查看。
  - 图片题会从模型解答里的题目标题自动命名；用户手动修改的标题不会被覆盖。
- **讲解风格**：直接讲解，或"先给提示，让我自己想"
  - 设置分为“学习设置”和“高级配置”；首次配置供应商后，日常使用无需接触模型参数。
- **云端同步**：部署到自己的服务器，手机、电脑登录同一个密码，记录自动同步
- **语音**：支持浏览器声音与小米 MiMo，正文、动画和试听使用同一套配置；倍速播放保持音调，完整音频备好后再播放。

## 模型和小米语音配置

1. 打开“设置 → 高级配置”，填写模型供应商的 Base URL 和 API Key，点击“获取模型列表”。成功后供应商与模型列表保存到服务器；获取失败时保留之前的配置。
2. 从菜单选择解题模型和讲解剧本模型，保存设置。以后可直接在输入框中切换解题模型、思考强度和讲解方式。
3. 打开“学习设置 → 朗读”，选择“小米 MiMo”，填入小米语音密钥。默认地址 `https://api.xiaomimimo.com/v1`、模型 `mimo-v2.5-tts` 已准备好，可选音色和声音风格。
4. 点击“保存并试听”。正文朗读和动画讲解也会使用这份服务器配置。密钥留空表示保留已保存值；完整密钥不会返回浏览器。更换语音地址时需要重新填写密钥。

小米使用[官方语音合成协议](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5)：服务端向 `/chat/completions` 发送 `assistant` 朗读文本和 `audio` 配置，接收 Base64 WAV 后保存。

- 回复全文一次合成，准备期间朗读按钮灰显；完整音频下载好后才可播放。
- 动画一次提交全部步骤，服务端最多同时合成 3 步，所有步骤就绪后才开放有声播放。每步全文独立合成一次，以保证步骤跳转和画面同步；播放途中不再请求小米。
- 音频保存在 `data/speech-cache/`，按全文、模型、音色、风格和供应商配置区分，重复请求合并。重播、刷新、调速复用缓存；调速使用媒体元素的保音调功能。
- 缓存保留 7 天、上限 512 MB，自动清理；重启后仍可复用。页面退出只停止等待和播放，服务端继续完成正在准备的音频；重试仅补齐失败的部分。
- 准备失败时可以重试，动画也可先切换到无声模式。音频下载和任务查询都要求登录。

自动测试使用模拟供应商验证请求、缓存和播放状态，真实声音以所选音色的试听为准。

## 本地运行

需要 Node.js 24 以上。

```bash
npm install
cp .env.example .env      # 填入 LLM_API_KEY
npm run build
npm start                 # 打开 http://127.0.0.1:3000
```

开发时用 `npm run dev`（前端 http://localhost:5173，修改代码自动刷新）。

## 部署到服务器

见 [DEPLOY.md](DEPLOY.md)（宝塔面板 + PM2 + Nginx + HTTPS）。

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run probe` | 检测模型供应商支持哪些能力（对话、流式、图片、JSON 等） |
| `npm test` | 单元测试与接口测试 |
| `npm run test:e2e` | 用本机 Edge 浏览器做端到端测试（先 `npm run build`） |
| `npm run typecheck` | 类型检查 |
| `node --env-file=.env scripts/smoke-real.ts` | 用真实模型跑一遍解题和追问 |
| `node --env-file=.env scripts/try-scene.ts 0` | 用真实模型为示例题生成动画讲解 |
| `node scripts/shot-scene.ts <剧本.json>` | 把剧本逐步截图，检查画面 |
| `node scripts/reset-password.ts` | 忘记密码时清除密码 |

## 结构

```
server/        后端（Hono + Node 自带 SQLite）
  app.ts         接口：登录、设置、对话、动画讲解
  llm.ts         OpenAI 兼容接口客户端
  sceneGen.ts    生成剧本 → 校验验算 → 修正 的循环
  scenePrompt.ts 剧本格式说明（给模型看的）
shared/scene/  剧本格式、几何计算引擎、表达式求值、校验器、示例剧本（前后端共用）
web/src/       前端（React）
  scene/         SVG 绘图与讲解播放器
tests/         单元与接口测试（vitest）
e2e/           浏览器端到端测试
```

数据都在 `data/`：`sz-teacher.db`（记录、设置）和 `uploads/`（题目照片）。备份这个目录即可。
